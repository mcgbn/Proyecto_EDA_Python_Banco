# Proyecto_EDA_Python_Banco
Ejercicio de análisis de datos desde Python en un proyecto de documentos de marketing de un banco

El proceso incluye un primer paso de limpieza general en ambos documentos (carpeta notebook):
-  Comprobación de nulos y duplicados
-  Cambio de formatos que no se corresponden a las columnas
-  Homogeneización textos


Posteriormente, en limpieza avanzada, nos encargamos de (carpeta notebook):
- Datos nulos en ambos documentos  
- Creamos columnas nuevas con categorías para facilitar el análisis de los datos.

En ambos casos se crean documentos .csv con los cambios aplicados (en carpeta output).

A partir de esos documentos limpios:
- Unificamos ambos documentos en una misma tabla a través de los id únicos
- Realizamos un análisis y creamos gráficos (carpeta visualizaciones)

El informe explicativo con el análisis se encuentra también en el documento de word adjuntado "Análisis de campaña de marketing...".
